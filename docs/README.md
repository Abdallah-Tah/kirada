## Product boundary

Kirada's first release tracks rent and payment evidence; it does not hold or
settle rent money. Tenants pay the landlord directly using the payment account
published by the landlord, then upload proof for review. Automatic settlement
through a regulated payment provider is a later integration and must not be
described as available until it is enabled and tested.
